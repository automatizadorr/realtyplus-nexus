🎯 Objetivo de la Automatización

El workflow se ejecuta automáticamente según el horario configurado (diario, semanal, etc.) y realiza lo siguiente:

  1. Obtiene todos los leads etiquetados de Supabase (leads_campana donde tag_ids != null)
  2. Obtiene los nombres de cada etiqueta (lead_tags)
  3. Obtiene los mensajes recientes de cada lead (mensajes_whatsapp + mensajes_automatizacion)
  4. Procesa y agrupa los datos: leads por etiqueta, métricas de conversación, leads sin respuesta
  5. Genera un reporte HTML por email (o Slack/Telegram) con resumen ejecutivo + tabla detallada

Build Report Code (JavaScript)
Procesa todos los datos y genera el HTML del reporte
💡 Conectar las salidas de los 3 nodos anteriores. En n8n puedes usar Merge (modo "Keep All Data") para combinar los arrays antes de este nodo.
// ── Nodo Code — Build Report ─────────────────────────────────────────
// Conectar: Get Tags (nodo 2), Get Tagged Leads (nodo 3), Get Messages (nodo 4)

const tags    = $('Get Tags').all().map(i => i.json);
const leads   = $('Get Tagged Leads').all().map(i => i.json);
const msgsWA  = $('Get Messages WA').all().map(i => i.json);
const msgsAuto = $('Get Messages Auto').all().map(i => i.json);

// Mapas de utilidad
const tagMap = new Map(tags.map(t => [t.id, t]));
const today = new Date();
const dateStr = today.toLocaleDateString('es-ES', {day:'2-digit',month:'long',year:'numeric'});

// Métricas de mensajes por teléfono
const msgStats = new Map();
const allMsgs = [...msgsWA, ...msgsAuto];
for (const m of allMsgs) {
  if (!msgStats.has(m.telefono)) msgStats.set(m.telefono, {env:0, rec:0, last:null});
  const s = msgStats.get(m.telefono);
  m.direccion === 'outbound' ? s.env++ : s.rec++;
  if (!s.last || m.created_at > s.last) s.last = m.created_at;
}

// Agrupar leads por etiqueta
const byTag = new Map();
for (const l of leads) {
  for (const tid of (l.tag_ids || [])) {
    if (!byTag.has(tid)) byTag.set(tid, []);
    byTag.get(tid).push(l);
  }
}

// Métricas globales
const totalLeads    = leads.length;
const respondieron  = leads.filter(l => l.ha_respondido).length;
const botActivo     = leads.filter(l => l.bot_activo).length;
const sinRespuesta  = leads.filter(l => !l.ha_respondido && !l.archivado).length;
const tasa          = totalLeads > 0 ? Math.round(respondieron / totalLeads * 100) : 0;

// Formato fecha
const fmt = d => d ? new Date(d).toLocaleDateString('es-ES',{day:'2-digit',month:'2-digit',year:'2-digit'}) : '-';

// ── Construir HTML del reporte ────────────────────────────────────────
let tagSections = '';
for (const [tid, tLeads] of byTag) {
  const tag = tagMap.get(tid) || {nombre: tid, color: '#7c3aed'};
  const respTag = tLeads.filter(l => l.ha_respondido).length;

  let rows = tLeads.map(l => {
    const s = msgStats.get(l.telefono) || {env:0, rec:0, last:null};
    return `<tr>
      <td>${l.nombre || '-'}</td>
      <td>${l.telefono}</td>
      <td>${l.pais || '-'}</td>
      <td>${l.estado || '-'}</td>
      <td style="color:#22c55e">${s.env}</td>
      <td style="color:#3b82f6">${s.rec}</td>
      <td>${l.ha_respondido ? '✅' : '❌'}</td>
      <td>${fmt(s.last)}</td>
    </tr>`;
  }).join('');

  tagSections += `
    <h3 style="color:${tag.color};border-left:4px solid ${tag.color};padding-left:12px;margin:24px 0 12px">
      🏷 ${tag.nombre} — ${tLeads.length} leads · ${respTag} respondieron
    </h3>
    <table>
      <thead><tr style="background:#1a1d27">
        <th>Nombre</th><th>Teléfono</th><th>País</th><th>Estado</th>
        <th>Env</th><th>Rec</th><th>Respondió</th><th>Último msg</th>
      </tr></thead>
      <tbody>${rows}</tbody>
    </table>`;
}

const htmlReport = `<!DOCTYPE html>
<html><head><meta charset="UTF-8">
<style>
  body{font-family:Arial,sans-serif;background:#f8fafc;color:#1e293b;padding:24px;max-width:900px;margin:0 auto}
  h1{color:#7c3aed;border-bottom:2px solid #7c3aed;padding-bottom:8px}
  h3{margin-top:24px}
  .kpis{display:grid;grid-template-columns:repeat(4,1fr);gap:12px;margin:20px 0}
  .kpi{background:#fff;border:1px solid #e2e8f0;border-radius:8px;padding:16px;text-align:center}
  .kpi-num{font-size:28px;font-weight:700;color:#7c3aed}
  .kpi-label{font-size:12px;color:#64748b;margin-top:4px}
  table{width:100%;border-collapse:collapse;font-size:12px;margin:12px 0}
  th{background:#7c3aed;color:#fff;padding:8px 10px;text-align:left}
  td{padding:7px 10px;border-bottom:1px solid #e2e8f0}
  tr:nth-child(even)td{background:#f8fafc}
</style></head><body>
<h1>📊 Reporte de Leads Etiquetados — ${dateStr}</h1>
<div class="kpis">
  <div class="kpi"><div class="kpi-num">${totalLeads}</div><div class="kpi-label">Total etiquetados</div></div>
  <div class="kpi"><div class="kpi-num" style="color:#22c55e">${respondieron}</div><div class="kpi-label">Respondieron</div></div>
  <div class="kpi"><div class="kpi-num" style="color:#f97316">${sinRespuesta}</div><div class="kpi-label">Sin respuesta</div></div>
  <div class="kpi"><div class="kpi-num">${tasa}%</div><div class="kpi-label">Tasa respuesta</div></div>

return [{ json: {
  html: htmlReport,

🗄️ Queries SQL de Referencia (Supabase)

Ejecutar en el SQL Editor de Supabase para verificar datos antes de construir el workflow.

Ver todos los leads etiquetados con sus etiquetas

SELECT
  lc.nombre, lc.telefono, lc.email, lc.pais, lc.estado,
  lc.ha_respondido, lc.bot_activo, lc.ultimo_contacto_at,
  array_agg(lt.nombre) AS etiquetas
FROM leads_campana lc
JOIN lead_tags lt ON lt.id = ANY(lc.tag_ids)
WHERE lc.tag_ids IS NOT NULL
  AND lc.tag_ids != '{}'
  AND lc.archivado IS NOT TRUE
GROUP BY lc.id
ORDER BY lc.ultimo_contacto_at DESC NULLS LAST;

Resumen por etiqueta (para el widget de KPIs)

SELECT
  lt.nombre AS etiqueta,
  lt.color,
  COUNT(DISTINCT lc.id) AS total_leads,
  COUNT(DISTINCT lc.id) FILTER (WHERE lc.ha_respondido) AS respondieron,
  COUNT(DISTINCT lc.id) FILTER (WHERE lc.bot_activo) AS bot_activo
FROM lead_tags lt
LEFT JOIN leads_campana lc ON lt.id = ANY(lc.tag_ids)
GROUP BY lt.id, lt.nombre, lt.color
ORDER BY total_leads DESC;

Mensajes de los últimos 7 días de leads etiquetados

SELECT
  mw.telefono, lc.nombre, mw.direccion, mw.contenido, mw.created_at
FROM mensajes_whatsapp mw
JOIN leads_campana lc ON lc.telefono = mw.telefono
WHERE lc.tag_ids IS NOT NULL
  AND mw.created_at >= NOW() - INTERVAL '7 days'
ORDER BY mw.created_at DESC;
